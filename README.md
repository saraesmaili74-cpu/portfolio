# Sara Esmaeili Portfolio

## Site map

- `index.html` — Home
- `work.html` — Case Studies archive
- `case-mehrabani.html` — First complete case study
- `templates.html` — Framer templates, landing pages, UI explorations, and screenshot-led work
- `about.html`, `resume.html`, `contact.html` — Supporting portfolio pages

## Adding a future case study

1. Duplicate `case-mehrabani.html` and rename it, for example `case-sora.html`.
2. Replace the copy and images using the sequence in `CASE_STUDY_TEMPLATE.md`.
3. Add a linked card to `work.html`.
4. Check desktop and mobile layouts before publishing.

## Adding a visual/template project

1. Add a compressed cover image to `assets/`.
2. Duplicate one card in `templates.html`.
3. Replace its title, one-sentence context, status, and optional external link.
4. Keep the explanation short; this page is for visual work that does not need a full case study.
